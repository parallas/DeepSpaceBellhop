Long time no see, operators!

It's Deep Space Bellhop's birthday today, which also means it's Parallas' birthday too! Happy birthday us!!

To celebrate, we've put together a small update to the game. Details are below!

The Anniversary Update (1.1.0) adds birthday-exclusive visual changes that appear on April 10th every year, and fixes several small issues.

# Changes

- On April 10th every year, everyone wears a birthday hat!
- The text in the intro stays on screen for slightly longer (unfortunately, the music timing makes it hard to keep it on screen for any longer than this)


# Bug Fixes

- Switching language no longer catastrophically breaks the game beyond repair. Really sorry about that one!!
- Fixed a single invalid letter in the French translation.
- Tweaked the Green Axolotl and Robot's dialog in the French translation.
- For Windows and Linux users, Crash logs are now stored outside of the game folder. For Mac users, the logs are stored in the "logs" folder inside the local game files. These are the new locations:
  - Windows: `C://Users/<your user name>/AppData/Local/parallas/Deep Space Bellhop/logs/`
  - Linux and SteamOS: `~/.local/share/parallas/Deep Space Bellhop/logs/`
